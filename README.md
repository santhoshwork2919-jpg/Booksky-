# 📚 Booksky

**Booksky** is a mini book management web app built using JavaScript. It allows users to add, view, and manage their personal book collection through a simple and intuitive interface.

## ✨ Features

- Add new books with details (title, author, etc.)
- View your book collection in one place
- Remove/manage existing entries
- Simple, lightweight, and beginner-friendly codebase

## 🚀 Getting Started

1. Clone the repository
   ```bash
   git clone https://github.com/santhoshwork2919-jpg/Booksky-.git
   ```
2. Navigate to the project folder
   ```bash
   cd Booksky-/booksky
   ```
3. Open `index.html` in your browser to run the app.
